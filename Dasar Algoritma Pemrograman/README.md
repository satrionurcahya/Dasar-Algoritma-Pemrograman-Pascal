## Cara Menjalankan

Pastikan **Free Pascal Compiler (FPC)** sudah terinstall.

```bash
# Compile
fpc nama_file.pas

# Jalankan (Windows)
nama_file.exe

# Jalankan (Linux/Mac)
./nama_file
