# Tugas Pengantar UTS — Pemecahan Uang

## Deskripsi
Buatlah program untuk memecah sejumlah uang ke dalam pecahan 
**Rp50.000, Rp20.000, dan Rp5.000**.

## Ketentuan
1. Input berupa nominal uang (bilangan bulat).
2. Nominal hanya diproses jika merupakan **kelipatan Rp5.000**.
3. Jika bukan kelipatan Rp5.000, tampilkan pesan kesalahan.
4. Pemecahan dilakukan dengan prioritas:
   - Rp50.000 sebanyak mungkin
   - Rp20.000 dari sisa
   - Rp5.000 dari sisa akhir
5. Hasil pemecahan disimpan dalam **tipe data bentukan** (`record`).
6. Program menyediakan **menu berulang** sampai pengguna memilih keluar.
7. **Tidak diperbolehkan menggunakan array.**

## Konsep yang Digunakan
- Tipe data bentukan
- Kondisional bertingkat
- Perulangan
- Prosedur dan fungsi

## Pengumpulan
- File program: `pemecahan_uang.pas`
