# Tugas Besar — Aplikasi CRUD

## Deskripsi
Buatlah sebuah program menggunakan bahasa **Pascal** yang menerapkan konsep 
**CRUD (Create, Read, Update, Delete)** pada sebuah studi kasus bebas 
(misalnya: data mahasiswa, data barang, data buku, dll).

## Ketentuan
1. Program memiliki **menu utama** dengan minimal 5 pilihan:
   - Tambah Data (Create)
   - Tampilkan Data (Read)
   - Ubah Data (Update)
   - Hapus Data (Delete)
   - Keluar
2. Data disimpan menggunakan **array of record**.
3. Setiap operasi CRUD dibuat dalam **prosedur/fungsi terpisah**.
4. Wajib menggunakan:
   - Tipe data bentukan (`record`)
   - Array
   - Perulangan (`while` / `repeat` / `for`)
   - Kondisional bertingkat
5. Jumlah data maksimum dibatasi (misal 100).
6. Program berjalan berulang sampai pengguna memilih menu keluar.

## Output yang Diharapkan
- Data dapat ditambahkan, ditampilkan, diubah, dan dihapus.
- Tampilan menu dan data tersusun rapi.

## Pengumpulan
- File program: `nama_file.pas`
